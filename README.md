# Newtonity Technologies — React landing page

A responsive one-page technology company website built with React, Vite and Lucide icons.

## Run locally
1. Install Node.js (18+ recommended).
2. Open this folder in VS Code.
3. Run `npm install`
4. Run `npm run dev`
5. Open the local URL shown by Vite.

## Customize before publishing
- Update the contact email in `src/components/Contact.jsx` and `src/components/Footer.jsx`.
- Replace the sample portfolio concepts in `src/data.js` and `src/components/Work.jsx` with real projects.
- Replace the social links (`href="#"`) in `Footer.jsx`.
- Connect the contact form to your backend or a form service. It currently opens the visitor's email app using a `mailto:` link.
- Edit colors and typography at the top of `src/styles.css`.

## Brand system
- Midnight navy: `#0B1220`
- Electric blue: `#4263F5`
- Cyan accent: `#35C8DC`
- Soft background: `#F5F7FB`
- Heading font: Space Grotesk
- Body font: DM Sans
